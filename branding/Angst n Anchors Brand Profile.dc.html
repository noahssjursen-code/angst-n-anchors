Design every label for the longest language, not English. German and Russian run 30–40% longer; Finnish worse. Panels sized to English copy break the first time the game is translated.

+40% rule. Every button, tab and label is laid out with 40% spare width, or is free to grow. Fixed-width text containers are forbidden.
Data never translates. Mono readouts — KN, HDG, coordinates, ℳ amounts, MMSI — stay in source form in every locale. Only the label beside them translates.
No text baked into art. Signage, port names and UI labels are live text nodes, so a locale swap never needs a new texture.
Glyph coverage — Saira has no Cyrillic. Saira and Saira Condensed cover Latin, Latin Extended and Vietnamese only. JetBrains Mono does carry Cyrillic, so data readouts are safe in any locale, but display and UI text need a substitute face: PT Sans Narrow 700 for display and PT Sans for UI — both Google Fonts, OFL, designed for Cyrillic, and close enough in proportion to hold the layout. Greek needs the same treatment; CJK needs a separate face and a rebuilt line-height scale. Decide per locale before promising it.
Locale font table. Ship it as data, not per-scene overrides: en/de/fr/es/it/pl → Saira · ru/uk → PT Sans · data → JetBrains Mono (all locales).
Condensed has a floor. Never solve overflow by shrinking type below 24 px at 1080p — wrap to two lines or shorten the source string.
05 · Layout rules
RULE 1 — the centre of the screen belongs to the sea. Instruments live on edges and corners.
RULE 2 — one horizontal "waterline" datum per screen; bars, bands and scrubbers sit on it.
RULE 3 — data is mono, feelings are the UI face. NPCs never speak in the data font.
06 · Spacing + sizing
Base unit 4 px at 1080p. Every gap, pad and offset is a step on this scale — no arbitrary values, so screens built by different hands still line up.

44 px is a floor, not a target. Anything clickable while the boat is moving gets 44 px minimum, gamepad or mouse.
Type sizes at 1080p: display 44 / 32 / 24, body 18, button 16, data mono 17, label mono 14. Micro mono 12 is permitted only for dense chart labels.
Scale with resolution, don't reflow. The HUD keeps its proportions at 1440p and 4K; panels grow, layout stays put.
07 · Motion
The game is slow; the interface is not. Motion exists to show where a thing came from, never to entertain.
MICRO 90 MS hover, chip select, toggle
CONTROL 160 MS buttons, tooltips, field focus
PANEL 240 MS cards, dialogue band, side panels
SCREEN 320 MS menu transitions, chart open/close
ENTER cubic-bezier(0.2, 0, 0, 1) decelerating
EXIT cubic-bezier(0.4, 0, 1, 1) accelerating
DATA linear — numbers never ease
No bounce, no overshoot, no spring. Nothing in a harbour is springy.
Entering elements translate 8 px maximum and never scale. Panels slide from the edge they belong to.
Gauges and readouts tick linearly. An eased number is a lying number.
One animation per interaction — if two things move, the player doesn't know which one answered them.
Reduced motion is instant. Setting off = no transitions at all, no fade substitutes.
08 · Voice
— Deadpan, maritime, specific. "Storm in 3 hours" beats "Danger approaching!"
— The game never congratulates you. The harbour master might nod.
— Numbers are honest and mono. No fake precision, no exclamation marks in system text.
09 · Logo usage
— Minimum size 16 px. Clear space on all sides: the width of the ring.
— Amber #F2B233 backgrounds are reserved for the logo tile and marketing; in-game accent is brass #D99A1F.
— The mark is recoloured, never redrawn: single colour only, from the palette above.
— Tagline, when used: A LOW-POLY SHIPPING MMO — mono, tracked, never larger than the wordmark's x-height.

11 · Iconography
20 / 40 PX
20 px grid · 1.6 px ink stroke (1.8 for single-stroke icons) · square caps and joins · outlines only, fills reserved for tiny dots · one object per icon, drawn side-on or top-down like a chart symbol. Icons recolour like the logo: ink on paper, paper on sea, never multicolour.
12 · Standard shapes
Six shapes replace rounded rectangles and circles across the product — the vocabulary of a hull plate and a chart symbol, not a web card. No chamfers, no rounded corners. Panels stay square and earn their character from a brass rule; only shapes that mean something — direction, a hull, a flag, a zone — break the rectangle, and they break it along a whole edge.

One shape per component, never two cuts on the same element. No chamfered corners, no rounded corners — a corner is square or the whole edge moves. Circles survive only as instrument dials, the logo's ring, and buoy markers.
13 · Currency + formats
8 800
Marks. Custom M glyph (ships as a font/texture asset, not a Unicode character), space before amount, thin-space thousands, no decimals — the economy deals in whole marks.
TIME 14:42 — 24-hour, no seconds unless it's a race
TUE 26 JUL — day + date, no year in HUD
59°02'N 005°27'E — degrees + minutes, no decimals
10.4 KN · HDG 074° — one decimal for speed, three digits for headings
18.4 T · 1.2 M — metric, one decimal, unit after a space
All of the above always in JetBrains Mono, never bold. On dark strips the value is brass and the label paper; on paper both are ink.

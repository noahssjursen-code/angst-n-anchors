HARBOUR NAMES - 15 OCTOBER 2026

Port records -> Harbour contains a short owner-only name form. Enter or Save
harbour name submits rename_port through the same authority command mechanism
as construction. It never edits the document or scene name directly. Unicode
names are supported, surrounding spaces trimmed, maximum length 80 characters.
Empty names, control characters, extra fields and foreign/stale actors reject.

The port ID, world location, plots, berth IDs, equipment, cargo and permissions
are unchanged. A single revision/event/receipt persists the name; duplicate
commands and repeated events are harmless. Event replay explicitly handles
the scalar name field, while existing array changes retain their validation.
Old documents without a name remain valid.

Inspector title, workshop heading, actual chart and saved JSON use the new name.
The name form defaults read-only. The isolated workshop explicitly supplies its
owner role; this is not authentication for a future multiplayer adapter.
Native inspection caught an inherited opaque dark focus style hiding the text;
both name fields in this paper panel now use a transparent focus outline.

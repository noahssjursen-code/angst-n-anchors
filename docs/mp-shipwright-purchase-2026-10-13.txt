Multiplayer shipwright repair - 2026-10-13

Cause: the UI disabled remote stock and the purchase method rejected remote
orders. Replication did not provide a working payment/purchase service.

PortServiceDesk.purchase now awaits server confirmation. The server endpoint
POST /v1/vessels/purchase authenticates captain ownership, selects its own stock
blueprint/price and rejects a mismatching quote. One PostgreSQL transaction locks
the balance, saves construction, creates ownership, debits funds and stores a
retry receipt. Repeated orders cannot charge twice; conflicting requests fail.
VesselSync merges the returned ship into the existing fleet, preserving an
already active vessel. No local registration substitutes for a failed purchase.

All six non-draft offers, including Coastal Express, are in shipwright_stock.json.
This separate sale export avoids changing construction identity when prices or
stock arrangements change. Existing construction catalog hashes are unchanged.
tools/export_gameplay_catalog.tscn now writes both exports; copy the sale export
to sibling server internal/gameplay/shipwright_stock.json when updating stock.
